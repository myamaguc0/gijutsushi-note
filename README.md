# 技術士二次 合格ノート

技術士第二次試験（**電気電子部門・電力・エネルギーシステム**）の学習を、ブラウザだけで完結させるアプリです。
インストール不要・無料。データはお使いのブラウザの中にだけ保存されます。

## 機能

| 機能 | 内容 |
|---|---|
| キーワードカード | 電力・エネルギーシステム（旧：発送配変電）と必須科目Ⅰの重要テーマ37枚（定義・課題・対策の形）に加え、Ⅱ-1用「4段構成」（背景・原理→現象→対策→数値・規格）の変電カード30枚、Ⅰ・Ⅲ用「土俵ストーリー」（どの題材でも得意分野に引き込む骨子）5本を収録。覚えた度合いに応じて次の出題日が決まる間隔反復方式。追加・編集も自由 |
| 論文練習 | 本番と同じ答案用紙（24字×25行＝600字）で、行数・枚数・残り時間・ペース（予定より何行先行／遅れ）を表示。書きかけは自動保存 |
| 選択科目 通し模試 | Ⅱ-1 → Ⅱ-2 → Ⅲ の6枚を本番と同じ 3時間30分 で続けて書く。着手順は「Ⅲ先行」も選べる。設問ごとの目標時間（30／60／105分＋見直し15分）に対する遅れ、行数、分量不足の判定を表示 |
| 自動チェック | 分量、文体の混在、あいまいな表現、長すぎる一文、設問に対応する見出し、「観点」「リスク」「倫理」の記述、専門用語の使用数。さらに過去の添削で繰り返し指摘された弱点（課題表記の統一・観点の重複、観点不要時の記述、解決策と課題の連動、設問(3)のリスクの連動、数値の有無、問題文の重要語の使用率＝題意ズレ、Ⅱ-1のメカニズム説明と見出し過多、Ⅱ-2の留意点・調整相手、空白行・改行過多、同音異義語）を機械的に検出 |
| 自己採点 | 技術士に求められる資質能力（コンピテンシー）7項目で、×△○の採点 |
| AI添削の依頼文 | 問題・答案・採点観点に加え、過去に指摘された弱点の一覧と自分の反省メモを添えた依頼文をコピーし、ChatGPT・Claude・Gemini などに貼り付けて「再発チェック」つきの添削を受けられる |
| 週間計画 | 平日は朝30分（月水金：Ⅱ-1を1枚、火木：AI添削と復習）、週末は2時間（土：Ⅱ-2またはⅢ、日：書き直し）の計画をホームに曜日ごとに表示 |
| 業務内容の詳細 | 受験申込書の「業務内容の詳細」（720字）を、立場・課題・提案・成果の構成で下書き。字数カウントとAI添削の依頼文つき |
| 学習記録 | 試験日までのカウントダウン、連続学習日数、直近16週の学習カレンダー |

## 使い方

1. `index.html` をブラウザ（Chrome / Edge / Safari）で開きます。GitHub Pages で公開すると、スマホからも使えます。
2. 「設定・バックアップ」で筆記試験日を入力します。
3. 毎日「今日の復習」でカードを回し、週に数本、時間を計って論文を書きます。
4. 書き終えたら振り返り画面で自動チェックと自己採点を行い、「AI添削の依頼文をコピー」で添削を受けます。

## 収録問題について

収録している練習問題は、本試験の出題形式に合わせた**オリジナル問題**です。過去問は日本技術士会のWebサイトで公開されているので、「＋ 問題を追加」から個人の学習用に登録してください。
キーワードカードの数値・制度は改定されることがあります。最新の公表資料で確認し、自分の言葉に書き換えて使うことをおすすめします。
